# redteam-vulnerable-webapp-lab

**Намеренно уязвимое** учебное веб-приложение для отработки атак и защит в изолированной среде.
Запускать ТОЛЬКО локально/в изолированной сети. Никогда не выставлять в интернет.

## Уязвимости для изучения
- SQL Injection (форма логина)
- Reflected XSS (поиск)
- IDOR (просмотр профиля по id)

## Запуск
```bash
docker compose up -d
# http://localhost:5000
```

## Цель
Найти уязвимости, эксплуатировать, затем — **исправить** (ветка `fixed/`).

## Дополнительно
- `app/app_fixed.py` — исправленная версия приложения (SQLi и XSS закрыты); ветки `fixed/` в репозитории нет, исправление лежит в этом файле.
- `docs/attack_walkthrough.md` — пошаговый разбор атак на стенд; `docs/owasp_mapping.md` — соответствие OWASP/CWE; `docs/safe_setup.md` — безопасный запуск.
- Уязвимость IDOR пока описана только как задание для самостоятельной реализации (`docs/attack_walkthrough.md`).
